How I work

Process over output.

  1. 01

    Understand deeply

    Before a single line of code, I map the problem space entirely — user flows, edge cases, technical constraints. The more you understand, the less you need to build.

  2. 02

    Design with intent

    Every visual decision earns its place. Typography, spacing, motion, color — I design in Figma first, so implementation is confident, not exploratory.

  3. 03

    Build incrementally

    Foundation first, then features, then finish. Each layer is solid before the next begins. Ship small, learn fast, iterate with precision.

  4. 04

    Polish obsessively

    The last 10% separates good from great. I invest disproportionate care into micro-interactions, empty states, error messages — the things nobody notices until they're absent.
